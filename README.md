# SmartTrip

AI-powered travel assistant built with Angular, Spring Boot and Spring AI.

## 🎯 Objective

SmartTrip is a portfolio project designed to explore modern AI application development.

The application will be able to:

- propose a day-by-day itinerary;
- recommend places;
- answer questions about a destination;
- adapt the itinerary according to user preferences;
- generate a travel checklist;
- use external data through tools;
- maintain conversations with users.
